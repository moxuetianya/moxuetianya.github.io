【qemu】qemu网络配置

1. 术语

namedescription
virtual networking device / NICqemu 模拟网卡
network backendqemu 网络后端

2. 基本介绍

QEMU 网络包含两个部分：

  • 提供给 guset 的模拟网卡（例如，PCI网卡）；
  • 与模拟网卡交互的网络后端（例如，将数据包放入主机网络）

每个部分都有一系列选项。默认情况下（即使不加任何 network 相关的参数），QEMU 将为 guest 创建：

  1. SLiRP 用户网络后端
  2. 合适的虚拟网络设备（例如，用于大多数 x86 PC guest 的 E1000 PCI 网卡）

注意：如果在命令行（通过 -net（已废弃）、-nic或 -netdev）指定任何网络选项，那么 QEMU 将要求您提供足以定义和连接这两个部分的选项。（忘记指定网络后端或网络虚拟设备会给出警告信息，如“Warning: netdev mynet0 has no**peer** ”，“Warning: hub 0 is not connected to host network” 或者**“Warning: hub 0 with no nics”，** 然后 VM 将启动，但是没有正常运行的网络） 注意：如果您使用（默认）SLiRP 用户网络，则 ping（ICMP）将不起作用，但 TCP 和 UDP 将起作用。不要尝试使用 ping 来测试您的 QEMU 网络配置。

3. 快速配置

QEMU配置网络环境通常有两种方式：

  • 可插拔网卡（pluggable NIC）
-device DEVNAME,netdev=NET-ID,... \
-netdev TYPE,id=NET-ID,...

注意：“-device ?”可以查看机器支持的设备（包含网卡设备）

  • 板载网卡（On-board NIC）
-nic TYPE,model=DEVNAME,...

注意：“-nic model=?”可以查看机器支持的 NIC 设备。

QEMU 支持的网络选项可通过“--help”来查看：

这里以 sifive 公司提供的 riscv 架构虚拟机 sifive_u 为例，介绍两种基本的配置模式：user 和 tap。

3.1 user 模式

已验证的选项配置参数：

id=STR: 网络唯一标识
net=ADDR[/MASK]: 子网段
host=ADDR: DHCP服务器地址（需与net保持对应）
hostname=HOST:
restrict=[on|off]: 是否与主机网络隔离
dhcpstart=ADDR: DHCP分配的起始地址（需与net保持对应）
dns=ADDR: 虚拟DNS服务器地址（需与net保持对应）
dnssearch=DOAMIN:
domainname=DOMAIN:
tftp=DIR: host端本地目录（这里仅使用tftp协议传输文件，未使用host端的tftpd-hpa服务）
tftp-server-name=NAME:
bootfile=FILE: 启动镜像的名称（针对u-boot）
hostfwd=RULE: host端口转发
guestfwd=RULE:
smb=DIR[,smbserver=ADDR]:
mac=MACADDR:

举例：

对于启动的 u-boot 镜像，可以采用静态配置的方式启动 kernel 镜像：

(u-boot) setenv ipaddr 192.168.1.1
(u-boot) setenv netmask 255.255.255.0
(u-boot) setenv gatewayip 192.168.1.2
(u-boot) setenv loadaddr 0x8xxxxxxx
(u-boot) setenv serverip localhost
(u-boot) setenv bootfile uImage_name
(u-boot) tftpboot

也可以采用动态获取的方式启动 kernel 镜像：（前提是已经在qemu参数中配置了 bootfile=uImage_name）

(u-boot) dhcp 0x8xxxxxxx

Limitations

slirp 架构（user networking）的网络拓扑作为默认开启选项，本质上是QEMU内置的DHCP服务器，配置简单，但延展性不强，不支持ICMPv6，性能和实用性均受到局限，See User-mode networking for more details，并且它是以 NAT（Network Address Translation）为基础实现的，其中存在的问题和限制，请参slirp#limitations 或 Issues and limitations。

3.2 tap 模式

已验证的选项参数：

id=STR: 网络唯一标识
fd=H:
fds=X:Y:…:Z:
ifname=NAME: tap设备的名称
script=FILE:
downscript=DFILE:
br=BRIDGE:
helper=HELPER:
sndbuf=NBYTES:
vnet_hdr=[on|off]:
vhost=[on|off]:
vhostfd=H:
vhostfds=x:y:...:z:
vhostforce=[on|off]:
queues=n:
poll-us=n:

举例：（搭建类似 SLiRP 架构的网络，与 host 主机外网连通）

sudo qemu-system-riscv64 -M sifive_u -m 256M -bios fw_payload.elf -kernel uImage -nic tap,id=net0,ifname=tap0,script=no,downscript=no

通过该方式启动QEMU并不会配置完整的拓扑网络。
