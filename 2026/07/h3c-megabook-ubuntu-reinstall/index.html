H3C MegaBook 重装 Ubuntu 指南

七月 28, 2026 [linux, hardware] #ubuntu #h3c #bios #ventoy

H3C MegaBook 出场预装 Windows，重装 Ubuntu 时遇到了两个典型的坑：无法进入 BIOS 和 Ventoy 安全启动验证失败。本文记录实测可行的解决方案。

问题一：按 F12 / F2 / Delete 都无法进入 BIOS

Windows 的快速启动导致键盘在开机阶段不被检测。以下方法 100% 成功：

  1. 在 Windows 系统中，打开 设置 → 系统 → 恢复。
  2. 找到 高级启动，点击右侧的 立即重新启动。
  3. 系统重启后进入蓝色菜单，依次选择：疑难解答 → 高级选项 → UEFI 固件设置。
  4. 点击 重启，电脑自动进入 BIOS。

进入 BIOS 后，建议关闭 Secure Boot（在 Security 选项卡下），方便后续操作。

问题二：Ventoy 启动报错 Verification failed: (0x1A) Security Violation

UEFI 安全启动不信任 Ventoy 的引导文件。可以用 Ventoy 自带的 MOK 证书注册解决，无需再次进入 BIOS：

  1. 看到报错界面后，按 Enter 键。
  2. 进入蓝黑色的 Shim UEFI Key Management（MOK 管理）界面。
  3. 用方向键选择 Enroll key from disk，回车。
  4. 选择 VTOYEFI 分区，回车。
  5. 选择 ENROLL_THIS_KEY_IN_MOK_MANAGER.CER，回车。
  6. 看到 Continue 提示，回车。
  7. 询问是否注册，选择 Yes。
  8. 回到主菜单，选择 Reboot 重启。

重启后再次从 U 盘启动，Ventoy 选单正常显示，即可开始安装 Ubuntu。

安装与驱动建议

H3C MegaBook 使用 Intel Core Ultra (Lunar Lake) 处理器，建议选择内核较新的 Ubuntu 版本（如 24.04 LTS 或更新版本），以获得更好的触控板、音频和电源管理支持。

安装完成后，打开 附加驱动（Additional Drivers） 检查显卡、无线网卡等是否需要闭源驱动。
