dashmap-hang — 最小复现样本

按生产真实锁序的 tokio 复现（dashmap 6.2.1）。详见 博客正文。

源码

  • Cargo.toml
  • src/main.rs — 入口：启动 server → client → watchdog
  • src/server.rs — server：Registry + 状态页 + A 对会话
  • src/client.rs — client：B 对并发注册 (Barrier 同时性)
  • src/watchdog.rs — watchdog：进度监控 + wchan/gdb 取证

构建与运行

# 下载全部源码（右键另存为，或 git clone 本仓库）
# 将上述文件按目录结构放置后：

cargo build --release
./target/release/dashmap-hang          # 默认 12 轮, ~10s 内命中
./target/release/dashmap-hang 24 500   # 自定义: 24 轮, 状态页 500ms

预期输出: HANG: insert() 永久卡死, writer=0 + gdb 栈显示 dashmap::lock::RawRwLock::lock_exclusive_slow ×2 (exit 42)
